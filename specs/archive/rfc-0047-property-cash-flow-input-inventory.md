# Specification: Property cash-flow input inventory (RFC 0047)

Status: **implemented on development branch; unreleased** · Opened 2026-09-13

RFC 0047 added a read-only inventory API and CLI command for RFC 0045 plan
authoring. It reports source variants, lease-up periods, supplemental rows,
stated metric names, and required coverage cells without classifying rows or
inferring expense, reserve, payment timing, zeros, or economic assertions.

The complete contract is [RFC 0047](../../docs/rfcs/0047-property-cash-flow-input-inventory.md).
