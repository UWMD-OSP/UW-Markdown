The consumers sit under a repository checkout whose own `node_modules` holds
workspace packages, so each check records every module it loads through a
Node resolve hook and fails if any resolves outside the consumer.

**All eight packages: 26/26 checks pass.**

- `@uwmd/core` and `@uwmd/core/browser` report core 4.1.0, Protocol 4.0.0 and
  Format 3.0. `@uwmd/verify` and `@uwmd/verify/browser` report

  verify/browser export, as the same objects.
