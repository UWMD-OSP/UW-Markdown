# 5.0.0 release-prepared record

Prepared **2026-10-14** (America/Phoenix) on canonical `UWMD-OSP/UW-Markdown`
`main` at `79d4c92e`, the merge of PR #341. This is wiki 11's
release-prepared state: final, dated, publication-neutral records.

It is not a publication receipt or a tag authorization. On 2026-10-14 the
owner approved preparing 5.0.0 and withheld tagging, publication, deployment
and npm setting changes.

The evidence it rests on is the
[next-release readiness assessment](../reviews/2026-10-14-next-release-readiness.md)
and the
[launch onboarding audit](../reviews/2026-10-14-launch-onboarding-audit.md).

## Owner decisions applied (2026-10-14)

1. **Versioning.** Core/CLI 5.0.0 is approved as the candidate, because
   PR #328 introduced genuine CLI compatibility breaks. Format 3.0 and
   Protocol 4.1.0 stay unchanged. Package versions stay independent; this is
   not a lockstep release.
2. **Node support.** Each package declares its own minimum. Signing and
   report declare the Node 20 floor they already required. Node 18 stays
   declared wherever it works.
3. **Format spec Part VI.** Its technical text is authoritative enough to
   reconcile, so outdated CLI descriptions got editorial corrections only.
   A real change to a conformance obligation goes through an RFC.
4. **Verification gates.** D-01 and D-10 are covered by permanent executable
   CLI regression checks, kept apart from normative portable conformance.
