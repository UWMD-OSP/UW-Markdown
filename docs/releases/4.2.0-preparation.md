# 4.2.0 release-prepared record

Prepared **2026-10-14** (America/Phoenix) on canonical `UWMD-OSP/UW-Markdown`
`main` at `7c2b9d84` (the merge of PR #325) plus PR #326. This is wiki 11's
release-prepared state: final, dated, publication-neutral records. RFC 0084

## Reconciled generation

The immutable annotated `v4.1.0` tag targets
`9d18a13c236b6ee46857382a25ec75c0ff6ccf86`. Since that tag, the generation
contains:

1. **4.1.0 publication reconciliation** (PR #323). Historical; it does not
   establish publication of 4.2.0.
2. **Canonical signature encodings** (PR #324, issue #322). `@uwmd/signing`
   refuses padded base64url, non-zero unused bits, impossible encoded lengths
   and wrong decoded widths as `malformed` (`INT-07` for blocks); three
   `conformance/signing/blocks/` cases pin it. No contract change.
3. **RFC 0084, document snapshot signatures** (PR #325, issue #321). Protocol
   §V.13 and the §V.11.2 clarification, `uw-document-signature.schema.json`,
   the `document-signature-verification` capability, codes `INT-09`–`INT-15`,
   `verifyDocumentSignature` / `resolveDocumentSigningSubject` /
   `documentSigningPayload` in `@uwmd/verify`, `signDocument` /
   `createDocumentSignatureVerifier` / `loadDocumentSigningKey` in
   `@uwmd/signing`, the CLI's `sign-document` and `verify
   --document-signature`, the `conformance/document-signatures/` suite and
   its 14 portable cases. `PROTOCOL_VERSION` moved to 4.1.0 in that PR.
4. **RFC 0082 draft** (PR #314). A draft agent proposal with no
   implementation; it ships no behavior and stays `draft`.
5. **Release hardening** (PR #326). `uwmd init` refuses to overwrite an
   existing file; `@uwmd/signing` has no static `node:` import and loads in a
   browser again; CLI help, the CLI and `@uwmd/verify` READMEs and wiki
   08/11 corrected; the verification review record.
6. **This preparation.** Package versions and pins, the receipt engine
   identity, the release records and the protocol status line.

RFC 0084 changes how a document is verified, additively, so the Protocol takes
a minor (wiki 11: from 3.0 the Protocol moves only when what a document means
or how it is verified changes).
