# Property reserve accounts — RFC 0064

All examples are synthetic. The source-example payload carries source-shaped locators for an owner contribution, contractor invoice draw and return of unused cash to the owner. They establish the producer’s classifications; pointers are not authentication of a source document.

Each directory carries a full document and a hand-authored verifier state/code expectation. The default suite checks every code and verdict, read-only behavior and unchanged gross expenditure. The portable driver invokes `verify-reserve-accounts --json`. Focused tests additionally retain RFC 0045 refusal and same-day custody row identities.


The large-cent draw/contribution and multiple-contribution fixtures expose binary64 residues that the pre-fix shared quantizer incorrectly returned unchanged. Both must verify after the shared quantizer fix; the large-cent one-cent mismatch must still emit RSV-06. The overflow-then-finite-periods fixture retains later finite evidence and a later RSV-06 while returning unverifiable / nonfinite_arithmetic.
