# Downloads

Start with a `.uwx.md` record, the complete structured underwriting file. No
account, connector, or preferred editor is required: compatible agents,
services, editors, and viewers can all load it. See
[UWX and UW Lite](/guide/lite-and-uwx) for the compact `.uw.md` summary
representation.

## Create a blank record

The quickest route is the published CLI, which fills in the identifying fields
for you:

```bash
npx @uwmd/cli init --output my-deal.uwx.md --asset-class office --tier analyst
```

See the [quickstart](/tutorials/quickstart) for the next steps.

## Blank templates

If you would rather start from a file, both templates are Format 2.0 UWX
records generated by `uwmd init`. They validate as they are, with one warning
asking for the property's unit count.

- <a href="/downloads/templates/blank-screener.uwx.md" download="blank-screener.uwx.md">Download the blank screener template (<code>.uwx.md</code>)</a>
  — a first-pass screening record.
- <a href="/downloads/templates/blank-analyst.uwx.md" download="blank-analyst.uwx.md">Download the blank analyst template (<code>.uwx.md</code>)</a>
  — the same structure marked for full underwriting.

Both default to multifamily. Replace the template `deal_id` and dates, and
change `asset_class` when appropriate.
