# RFC0089 selected-direction complete-model admission checkpoint

The owner selected the tagged/null identity, exact portable minimum, total lexical
XML, complete CSV carriers and complete subject direction on2026-10-17. RFC0089
remains draft. This experiment changes no normative schema, production decoder,
receipt/signature rule, version, capability manifest or conformance expectation.

The new synthetic ten-block model is authored here with explicit actor, review
and lifecycle declarations; no older fixture is repaired or treated as admitted.
It covers builtin singleton/variant, all three append arrays, tagged singleton
and null/default variants, explicit ordered history and an empty history array.
Unknown outer/block/content data, absent/null/empty values and valid Unicode stay
in the complete subject. It is a model, not attributable Markdown or proof of
physical source inventory. The booleans describe synthetic test blocks only.

`admission.test.mjs` uses installed Ajv2020 and the repository's unchanged block
schema. A cloned Envelope schema is modified **in memory only** for its candidate
stamp and tagged extension entries. Every other original requirement, including
`variantMap.minProperties:1`, is checked unchanged. The existing independent Node
empty-carrier semantic guard then checks exact identities/order/state/section and
received digest. This combines a schema engine with an existing research guard;
it is not a new independent complete Format validator or accepted codec.

Six tests cover a complete positive model and JSON round-trip,80 isolated
actor/review/lifecycle shape failures across its ten retained blocks,10 candidate
wrapper/identity/state refusals with exact schema-versus-semantic attribution,
valid NUL/noncharacter/supplementary and extreme finite-number data, and four
nonfinite/lone-surrogate refusals. Disposable models are restamped before inner
semantic controls so a stale digest cannot hide the intended guard. Input objects
and the normative schema remain unchanged.

The proof identifies exact remaining boundaries:

- Empty `sections` itself and explicit `superseded[id]:[]` are admitted. An empty
  builtin variant slot `sections[id]:{}` violates unchanged minProperties1.
  Earlier empty-carrier codec equality for that value proves carrier capacity;
  it cannot authorize model admission. Retain it only as a negative admission
  control. No extra owner choice or schema weakening is inferred.
- The current block schema describes but does not enforce conditional
  `agent/*`→agent_id, market_data_accepted→market_data_ref and
  inherited_assumption→inherited_from requirements. Three explicit missing-field
  controls remain schema-admitted, **not Format-valid**. Those require accepted
  current validation predicates; this experiment does not allocate diagnostics.
- Complete built-in section contracts, full conditional Format validation,
  source selection/physical accounting, codec transport domains and actual
  supported-subject document/receipt state machines remain separate gates.
  No raw cryptographic or model-schema success certifies those obligations.
