# Code of Conduct

This project adopts version 2.1 of the **Contributor Covenant**, a widely used
community code of conduct authored by Coraline Ada Ehmke.

The full, canonical text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt (plain text)

By participating in this project — opening issues, submitting pull requests,
contributing to discussions, or any other interaction in project spaces — you
agree to abide by the terms of the Contributor Covenant 2.1 as published at
the URL above.

## Reporting

To report a violation, contact the project maintainers via the email or
contact channel listed in the project README. Reports are handled
confidentially. Maintainers are obligated to respect the privacy and security
of the reporter.

## Scope

This Code of Conduct applies in all project spaces — the GitHub repository
(issues, pull requests, discussions, code review comments), any official
project communication channels, and public spaces where someone is
representing the project.

## Enforcement

Maintainers will follow the **Community Impact Guidelines** published at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
when determining the consequences for any action they deem in violation.
